## 决策

内容层使用 UTF-8 Markdown + YAML frontmatter，Git 作为同步与版本机制；各 AI 工具入口由脚本生成。

## 理由

- 所有 LLM 都能直接解析纯文本，人类可读、可 diff、可 grep。
- 曾尝试把共享清单写入某外部知识库服务，该服务需要双凭证而本机只有其一，只读请求全部鉴权失败，用户明确表示放弃。**共享链路不应依赖单一服务的凭证可用性**。
- 生成物提交进仓库，无构建环境的设备也能直接使用。

## 后果

- 代价：每次改内容层都要重跑生成脚本并提交 `dist/`。
- 约束：新增工具只加 adapter，不复制内容；外部服务仅可作为可选投影，不能成为真源。

## 备选（未采纳）

- 以外部知识库为真源 → 凭证依赖、不可 diff、迁移成本高。
- 每个工具各存一份入口副本 → 必然漂移。
